# Authentication-Based Web Project

## About the Project
This project focuses on authentication and web application security, including biometric verification, trust evaluation, and security-related modules.

## Features
- Authentication-based web application
- Face scanning module
- Voice scanning module
- Password hashing and verification
- Trust evaluation and Zero Trust-related components
- API and route testing
- Explainable AI components

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js

## Project Structure
- `public/` — Frontend files
- `server/` — Backend modules
- `test_api.js` — API tests
- `test_http.js` — HTTP tests
- `test_routes.js` — Route tests

## Installation
1. Install Node.js and npm.
2. Clone this repository.
3. Open the project folder in the terminal.
4. Run `npm install`.
5. Check `package.json` for the correct command to start the application.

## Security
Never upload passwords, API keys, or sensitive user information to GitHub.
